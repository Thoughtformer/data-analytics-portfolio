# Project Charter

## Project Title

**Closing the Digital Support Gap: A Data-Driven Case for Community Technology Education, Repair, and Reuse**

## Purpose

Evaluate whether public evidence supports a limited community technology pilot that combines device refurbishment and reuse, hands-on technical training, technology access, personalized digital support, older-adult assistance, fraud-awareness support, and electronic-waste reduction.

## Primary Decision Question

**Should a community organization, municipality, library system, foundation, or nonprofit fund a limited pilot of an integrated community technology initiative?**

## Decision Standard

The project will recommend a limited pilot only if the evidence demonstrates:

1. measurable technology-access or digital-support need;
2. meaningful repair or reuse potential;
3. a plausible pathway for training and community support;
4. public or environmental benefit; and
5. outcomes that can be measured during a pilot.

## Evidence Chain

**Measurable need → available resource → trainable human capital → intervention → measurable outcomes**

## Scope

### Included

- Household and individual technology-use patterns
- Digital engagement by age, income, and education
- Repair outcomes for laptops, desktops, mobile phones, and tablets
- Documented end-of-life repair barriers
- Comparable community technology and digital-literacy programs
- Fraud-awareness and older-adult support evidence
- Environmental scenario modeling for portable electronic-device reuse and recycling

### Excluded

- Claims that the analyzed datasets directly measure digital literacy or technical proficiency
- Claims that Open Repair records represent the U.S. population
- Claims that modeled WARM benefits are measured program outcomes
- Immediate recommendation for full-scale implementation without a pilot evaluation

## Primary Data Sources

- National Telecommunications and Information Administration (NTIA), 2023 Internet Use Survey
- Open Repair Alliance, Open Repair Data
- U.S. Environmental Protection Agency (EPA), Waste Reduction Model (WARM)
- Public research and comparable-program documentation recorded in the source register

## Analytical Tools

- Python / pandas
- SQL / Google BigQuery
- Tableau Desktop Public Edition
- Microsoft PowerPoint
- Git / GitHub

## Core Deliverables

- Reproducible Python analysis scripts
- SQL validation queries
- Processed working datasets
- Analysis result tables
- Tableau workbook
- Evidence synthesis
- Recommendation framework
- Final presentation

## Final Recommendation Standard

The project is designed to support a **limited, measurement-focused pilot** when warranted by the evidence. Any pilot should establish measurable objectives and be evaluated before broader implementation.
