# Raw Data

This folder documents original source datasets used in the project.

Large raw source files may be stored locally rather than committed directly to GitHub. Official source links, filenames, versions, and access dates are documented so the original data can be obtained independently.

## P01 — NTIA Internet Use Survey

**Source:** National Telecommunications and Information Administration (NTIA)

**Dataset:** 2023 Internet Use Survey

**Official source:**  
https://www.ntia.gov/page/download-ntia-internet-use-survey-datasets

**Storage:** Local raw-data directory

**Reason not stored in GitHub:** Source CSV exceeds GitHub's browser upload limit.

**Handling:** Original file will remain unchanged. Any cleaned, filtered, or derived datasets used in the project will be stored separately under `data/processed/`.

## Data Integrity

Raw files will not be edited or overwritten.

All cleaning and transformation steps will be documented and performed on copies of the original data.
