## Project Overview

This case study will investigate a potentially overlooked issue involving systems or processes using data analysis to identify meaningful trends, communicate findings clearly, and develop actionable recommendations.


## Project Objective

The objective of this project is to identify a meaningful systems or process-related problem, analyze reliable data for patterns or trends, and determine whether the findings support a practical recommendation or course of action.

## Analysis Process

This project will follow the six phases of the Google data analysis process:

2. Prepare — identify and collect relevant data.
3. Process — clean and organize the data.
4. Analyze — examine the data for patterns, trends, and relationships.
5. Share — communicate findings through clear visualizations and explanations.
