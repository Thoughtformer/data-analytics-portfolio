# Analysis Results

This folder contains output files generated by the capstone analysis scripts.

These files represent derived analytical results, not raw source data.

---

## Current Results

### `ntia_age_technology_use.csv`

Weighted percentage estimates of technology use by age group using the NTIA 2023 Internet Use Survey working dataset.

The analysis compares:

- Laptop use
- Desktop computer use
- Tablet use
- Smartphone use
- Internet use at home

Age groups:

- 3–17
- 18–34
- 35–49
- 50–64
- 65–74
- 75+

#### Key Finding

Among adults, reported technology use generally declines with age.

The largest differences are visible in:

- Laptop use
- Smartphone use
- Internet use at home

The 3–17 group is treated separately because technology-use behavior among children differs from adult use patterns.

---

### `ntia_income_technology_use.csv`

Weighted percentage estimates of technology use by household/family income category.

Income groups:

- Under $25,000
- $25,000–$49,999
- $50,000–$74,999
- $75,000–$99,999
- $100,000–$149,999
- $150,000+

#### Key Finding

Reported technology use rises consistently as household income increases.

Laptop use shows one of the strongest differences:

- Under $25,000: 34.2%
- $25,000–$49,999: 42.0%
- $50,000–$74,999: 51.2%
- $75,000–$99,999: 56.3%
- $100,000–$149,999: 61.7%
- $150,000+: 68.0%

Internet use at home also rises across income groups:

- Under $25,000: 67.1%
- $25,000–$49,999: 73.8%
- $50,000–$74,999: 79.1%
- $75,000–$99,999: 81.6%
- $100,000–$149,999: 83.1%
- $150,000+: 83.8%

These results indicate a strong association between household economic resources and reported technology use.

---

## Method

Percentages are calculated using the NTIA person-level survey weight `PWSSWGT`.

Only records eligible for each technology-use question are included in the denominator.

Survey responses are coded as:

- `1` = Yes
- `2` = No
- `-1` = Not in universe

Records coded `-1` are excluded from percentage calculations rather than treated as "No."

## Interpretation Notes

These analyses identify associations in survey data.

They do not demonstrate that age or income directly causes differences in technology use.

The NTIA variables used here measure reported technology use and should not automatically be interpreted as direct measures of device ownership or household access.
