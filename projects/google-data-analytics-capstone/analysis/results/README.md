# Analysis Results

This folder contains output files generated by the capstone analysis scripts.

These files represent derived analytical results, not raw source data.

---

## Current Results

### `ntia_age_technology_use.csv`

Weighted percentage estimates of technology use by age group using the NTIA 2023 Internet Use Survey working dataset.

The analysis compares:

- Laptop use
- Desktop computer use
- Tablet use
- Smartphone use
- Internet use at home

Age groups:

- 3–17
- 18–34
- 35–49
- 50–64
- 65–74
- 75+

### Method

Percentages are calculated using the NTIA person-level survey weight `PWSSWGT`.

Only records eligible for each technology-use question are included in the denominator.

Survey responses coded as:

- `1` = Yes
- `2` = No
- `-1` = Not in universe

The `-1` records are excluded from the percentage calculation rather than treated as "No."

### Source

Derived from:

`data/processed/ntia_2023_working.csv`

Generated by:

`analysis/scripts/ntia_age_technology_use.py`

---

## Interpretation Notes

These results describe associations between age and reported technology use.

They should not be interpreted as evidence that age directly causes differences in technology use.

The 3–17 age group should be interpreted separately from adult groups because age-specific behavior and device use differ substantially among children.
